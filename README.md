# AtomSpectra Handheld (ESP32-S3)

[English version](README.en.md)

Автономный карманный прибор для гамма-спектрометра **KB Radar «Atom Spectra»**:
ESP32-S3 + сенсорный дисплей 3.5" + аккумулятор с модулем заряда + часы реального
времени + microSD. Спектр, мониторинг CPS и водопад видны прямо на экране прибора —
без телефона и компьютера, — а по WiFi доступен полный веб-интерфейс.

> **Основано на проекте [atomspectra-waterfall-esp32](https://github.com/VibeEngineering-LLC/atomspectra-waterfall-esp32)
> от VibeEngineering LLC** (ответвлено от версии `firmware-v1.1.2`, лицензия MIT).
> Приём спектра от прибора по USB, веб-интерфейс, водопад и формат ASWF, TCP-мост для
> BecqMoni / AtomSpectra, полевой режим WiFi — работа авторов исходного проекта.
> Спасибо им! Документация исходного проекта — в [docs/upstream](docs/upstream/README.md).

## Главные отличия от исходного проекта

### 1. Дисплей 3.5" с тачскрином — прибор без телефона

Модуль lcdwiki 3.5" IPS ST7796 (480×320, SPI) с емкостным тачем FT6336U. На экране —
мини-копия веб-интерфейса (LVGL 8):

- **Spectrum** — живой спектр (линейная шкала, двойной тап — логарифмическая), ось в кэВ
  по калибровке прибора; в шапке CPS, время набора, сумма, загрузка процессоров,
  статус прибора (точка мигает красным, пока идёт набор) и заряд батареи.
- **Monitor** — график CPS по интервалам и скользящее среднее (общая сессия с вебом).
- **Waterfall** — водопад (спектрограмма) в палитре Inferno.
- **Conf** — режим сети Indoor / Outdoor, **подключение к WiFi с экрана** (поиск сетей,
  ввод пароля на экранной клавиатуре, проверка перед сохранением), окно каналов.
- Кнопки **Start / Stop** (одна кнопка, меняется по состоянию), Clear, Save,
  **Files** — просмотр файлов на карте и открытие сохранённых спектров на графике.
- Калибровка тача по 5 точкам (страница «Система» веб-интерфейса).

![Плата с дисплеем](images/handheld-display.jpg)

### 2. Модуль заряда BQ25895 — работа от аккумулятора

- Питание от Li-ion аккумулятора, зарядка от USB-C (ток заряда настраивается в вебе).
- Спектрометр питается **5 В от аккумулятора** через повышающий преобразователь модуля
  (режим OTG) — прибор полностью автономен.
- Уровень заряда и статус зарядки — на экране и в вебе, диагностика регистров и сбоев
  питания на странице «Система».

### 3. Часы DS3231 — точное время без интернета

- Время хранится в часах с батарейкой и выставляется при включении — метки спектров,
  строк водопада и интервалов мониторинга верны и в поле, без SNTP и без телефона.
- Часы подстраиваются от SNTP или от браузера, когда они доступны.

### И ещё

- **microSD** (слот модуля дисплея): сохранённые спектры, сегменты водопада, сессии
  мониторинга (CSV), автосохранение текущего спектра. Во внутренний флеш пользовательские
  данные не пишутся — запись во флеш мешала приёму данных от прибора.
- Страница **«Файлы»** в вебе: просмотр (график спектра, CSV мониторинга, картинка
  водопада), скачивание, удаление по одному и пачкой.
- **Обновление прошивки по WiFi** загрузкой файла (страница «Система»), с откатом на
  прежнюю прошивку, если новая не запустилась.
- Перенесены исправления из новых версий исходного проекта: восстановление после
  зависания USB, сторож набора (сам перезапускает набор после перезагрузки прибора),
  сохранение спектра при обрыве питания прибора, чтение калибровки с прибора, защита от
  ошибочного удаления, повтор команд после перезагрузки платы.
- Убрано: Ethernet W5500 (выводы отданы дисплею и карте).

## Железо

| Узел | Подключение |
|---|---|
| Плата | ESP32-S3-DevKitC-1 **N16R8** (16 МБ флеш, 8 МБ PSRAM) |
| Спектрометр | USB (USB-OTG ESP32-S3, GPIO19/20), как в исходном проекте — см. [INSTALL.md](INSTALL.md) |
| Дисплей ST7796 (SPI2) | CS 4, DC 5, MOSI 11, SCLK 12, MISO 13, RST 14; питание 3.3 В |
| Карта microSD (слот дисплея) | CS 10, шина SPI общая с дисплеем |
| Тач FT6336U (I2C) | SDA 8, SCL 9, RST 7, INT 15, адрес 0x38 |
| Модуль заряда BQ25895 (I2C) | SDA 8, SCL 9, адрес 0x6A |
| Часы DS3231 (I2C) | SDA 8, SCL 9, адрес 0x68; питание **3.3 В** |
| RGB-светодиод WS2812 | GPIO48 |

## Прошивка

**Готовая** — в разделе [Releases](../../releases):

- `firmware.factory.bin` — полный образ для первой прошивки по USB:
  `esptool.py --chip esp32s3 -p COMx -b 460800 write_flash 0x0 firmware.factory.bin`.
  Стирает настройки (WiFi нужно будет ввести заново).
- `atomspectra_gw.bin` — для обновления по WiFi: веб-интерфейс → «Система» →
  «Загрузить прошивку по WiFi». Настройки и данные сохраняются.

Таблица разделов с OTA (`ota_0`/`ota_1` по 3 МБ). Переход с исходного проекта или с
версии без OTA — только прошивкой по USB.

**Из исходников** — ESP-IDF v5.4:

```
idf.py set-target esp32s3   # один раз
idf.py build
idf.py -p COMx flash monitor
```

Первый запуск: плата поднимает точку доступа `AtomSpectra-Setup` — выберите домашнюю
сеть в портале; либо подключите WiFi прямо с экрана (Conf → WiFi).
